- [x] 根据目标方案导出 NCNN
- [x] 把导出的模型文件放入 `exports/`
- [x] 记录输入尺寸、类别顺序和模型切换索引

推荐优先级：

1. NCNN：适合普通安卓 CPU 本地推理，工程接入相对直接。
2. TFLite：适合尝试 NNAPI 或部分手机加速能力。
3. ONNX：适合作为中间验证格式，不建议直接作为安卓最终运行格式。

## 通过标准

- 手机可以离线完成检测，不依赖网络或服务器。
- 单张测试图片能稳定输出检测框、类别和置信度。
- 手机端与电脑端检测结果没有明显偏差。
- 推理耗时达到目标设备可接受范围。
- 模型文件、类别名、输入尺寸和后处理参数都有记录。
